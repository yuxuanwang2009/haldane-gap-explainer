# Scene builder guide (read fully before writing a chapter)

## Files
- `scenes/common.py` — palette, `T()` (LaTeX text), `M()` (math), `caption()`, `title_card()`, `NarratedScene`.
- `scenes/visuals.py` — shared objects (spin chains/rings, level diagrams, gap braces, the L×β torus,
  weight bars, bond histories, the (log L, log β) plane). Reuse them; extend them only if the change
  keeps other chapters working (add new functions rather than changing signatures).
- `script/narration.json` — the narration (source of truth for segment ids and wording).
- `script/storyboard.md` — visual direction per segment.
- `audio/durations.json` — seconds per segment (generated by `tools/tts.py`).
- `data/*.csv` — real numbers for plots (never invent data; if a plot needs numbers that are not
  in `data/`, compute them or take them verbatim from the paper/storyboard).

## A chapter file
`scenes/chNN_<slug>.py`:
```python
from visuals import *   # also brings common.*

class ChNN(NarratedScene):
    CHAPTER = "chNN"
    def construct(self):
        with self.voice("s01") as d:          # d = narration seconds for s01
            ...self.play(..., run_time=0.4 * d)
        with self.voice("s02") as d:
            ...
```
- Every segment of the chapter in narration.json must be voiced exactly once, in order.
- Inside a `voice` block, size `run_time`s as fractions of `d` so animation tracks speech. The block
  automatically waits out the rest of the clip plus a short breath. Avoid making the animations in
  a block much longer than `d` (it delays the next clip and leaves dead air).
- Let important things land while they are being said; reveal an equation when the narration
  reaches it (split `d` into proportional chunks following the sentence order).
- End the chapter by fading everything out (`self.play(FadeOut(*self.mobjects))`) so chapter cuts
  are clean.

## Look and feel (3Blue1Brown)
- Dark background (set globally), Computer Modern via `T()`/`M()`. No other fonts.
- Semantic colours are fixed across the film: SPACE (blue) = spatial direction / spatial purity S /
  spatial transfer; TIME (orange) = imaginary time / thermal purity T / Boltzmann weights;
  DEFECT (yellow) = purity defects u, p, q; GAP (green) = the gap, proved statements; HALF (pink) =
  half-integer spin / gapless; INTEGER (light blue) = integer spin / gapped; SX/SY/SZ = x/y/z event
  labels; VIRTUAL (purple) = virtual spin-1/2s, MPS bonds, edge spins; DIM/FAINT for scaffolding.
- Smooth, purposeful motion: `Write`/`Create` for new math, `TransformMatchingTex` /
  `ReplacementTransform` to show one expression becoming another, `Indicate`/`Circumscribe` or a
  colour change to point. Don't animate everything at once; one focus at a time.
- Keep the frame uncluttered: at most ~3 visual groups on screen. Fade old material when the
  narration moves on.
- Text on screen is sparse: labels and key equations, not sentences. Narration carries the prose.

## Layout rules (hard)
- Frame is 14.2 × 8 units. Keep all content inside x ∈ [−6.7, 6.7], y ∈ [−3.7, 3.7].
- Minimum font sizes: body labels 28, equations 34, small annotations 24 (only if unavoidable).
- No overlaps: check with frames (below). Use `next_to(..., buff=...)`, `arrange`, `to_edge`.
- Equations wider than ~12 units must be split or scaled down (but not below the minimum size).
- Plots: use `Axes` with labelled axes (math labels via `M()`), tick labels at ≥ 24, data from
  `data/*.csv` (load with `numpy.genfromtxt(..., delimiter=",", names=True)` or `csv`).
  Log axes: plot log10 of the data on a linear axis and label ticks as 10^k.

## Render & inspect loop (mandatory)
Python env: the `haldane-manim` conda environment (`environment.yml`); `python` below means its interpreter.
1. Draft render (480p15, fast):
   `python tools/build.py render chNN --draft`
   (run from the project root; output in `output/chapters_draft/chNN.mp4`).
2. Extract frames: `python tools/build.py frames chNN --draft --every 3`
   → `output/frames/chNN/f001.png ...`. LOOK at the frames (Read tool on the PNG files).
   Also look at a frame near the end of each voice segment (use the timeline in
   `output/timelines/chNN.json` to compute times; extract a specific time with
   `ffmpeg -ss <t> -i output/chapters_draft/chNN.mp4 -frames:v 1 /tmp/x.png`).
3. Fix every overlap, clipping, illegible label, misaligned element, wrong colour semantics,
   or mismatch with the narration; re-render; re-inspect. Iterate until clean.
4. Check timing: `output/timelines/chNN.json` total should be close to the sum of clip durations
   + breaths (no long dead air; no segment block running > 1.3× its clip).

## Pitfalls
- `MathTex` substrings: use `{{ }}` or separate args for parts you'll colour/transform; or use
  `set_color_by_tex`. Test that `TransformMatchingTex` actually matches.
- `Tex`/`MathTex` need valid LaTeX; `\text{}` inside MathTex is fine; packages available: amsmath,
  amssymb, bm, dsfont.
- Don't use `always_redraw` with heavy Tex inside (slow). Use `ValueTracker` + `add_updater` on
  cheap mobjects, or `DecimalNumber`.
- `Arrow` tips scale with length; set `max_tip_length_to_length_ratio` for short arrows.
- Opacity of fills: set `fill_opacity` explicitly for shapes meant to be filled.
- Render time matters: avoid thousands of submobjects; keep each chapter's draft render < ~5 min.
- Do not modify `common.py`'s `NarratedScene` or `tools/*`. Do not modify other chapters' files.
